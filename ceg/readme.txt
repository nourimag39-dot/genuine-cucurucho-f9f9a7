CEG F/A WACHA - BACKEND PHP
================================

Ce dossier contient le backend PHP et le config.php fourni pour la base MySQL InfinityFree.

Installation InfinityFree:
1. Décompresser ce ZIP.
2. Envoyer le contenu du dossier "ceg" dans htdocs.
3. Vérifier que config.php est au même niveau que les fichiers PHP qui l'utilisent.
4. Importer la base SQL correspondante dans phpMyAdmin.
5. Tester ensuite les endpoints PHP depuis le frontend.

Important:
- Ne partagez pas publiquement le contenu de config.php : il contient les identifiants de la base.
